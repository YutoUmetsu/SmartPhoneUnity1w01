# SmartPhoneUnity1w01
///ゲーム概要
タップでレーンを移動し、落下物を回避して生き残るゲーム。
///操作方法
タップ　画面右側をタップで右のレーン、中央をタップで中央のレーン、左側をタップで左側のレーンに移動できる。
///使用技術
Unity（C＃）
///対応プラットフォーム
Andoroid
///工夫した点
時間経過で物が落下するまでの時間が速くなっていくようにした。また、スコアを0.1秒刻みで増加するようにした。
